Recovery for MM-REGISTERED / ECM-IDLE UEs -----

Persistent reachability fields and RestoreReachability logic are implemented,
but startup timer restoration is intentionally not activated because the MME
does not currently reconstruct authoritative UE/PDN contexts after restart.

database.mode: memory:
- UE state is discarded on restart.
- Reachability state is neither written nor restored.

persistent database modes:
- Reachability fields are written to recovery records.
- Existing startup behavior marks prior records stale.
- No live UE/session restoration currently occurs.
- RestoreReachability is reserved for a future full UE/session recovery loader.
